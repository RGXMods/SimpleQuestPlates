# Simple Quest Plates! 2.1.7-beta.1

- New **Unified nameplates** option (General > Position & Scale): quest
  overlays are parented into Blizzard's own nameplate UnitFrame and
  drawn above the health bar, so they move, scale and fade with the
  native nameplate (the integration technique MelloUI uses). Off by
  default; the legacy overlay remains available.
- Fixed default alignment in non-unified mode: quest icons now anchor
  against the nameplate's health bar container (falling back to the
  health bar, then the outer plate) instead of the outer plate
  boundary, whose geometry shifts with cast bars and buff space.
  Default Offset Y is now 0 = flush with the bar.
- The options banner preview demonstrates both modes: the quest icon snaps flush to the health bar and the caption reads Mode: Unified while enabled, and the Unified toggle lives in the left column.
- Overlays rebuild immediately when toggling Unified mode, and stale
  overlays are rebuilt when Blizzard replaces a plate's UnitFrame on
  reuse.

Requires RGX-Framework v2.7.8 or newer.
