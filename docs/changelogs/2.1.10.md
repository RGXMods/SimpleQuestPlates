- Framework adoption no longer creates a recursive C stack overflow when an
  old consumer publishes its live settings view as raw SavedVariables.
- Framework profile-store recovery keeps accepting later settings writes.
- Real SQP-defaults Lua 5.1 regressions verify alias recovery, explicit false/zero
  values and reload serialization. Current SQP already keeps its view local.
- Operator reports no issues after testing and approves stable publication.
  This is operator acceptance, not an independently captured client test matrix.

The earlier supplied error trace was old; these independently reproduced
defects are not established as its cause. The separately reported options
preview initialization issue is not included in this release.

Update both addons, then fully restart WoW. Do not delete SavedVariables.
