# SimpleQuestPlates v2.1.10-beta.1 - 2026-10-14

## Database hotfix dependency

- Requires **RGX-Framework 2.7.18-beta.1 or later**. Update both addons and fully
  restart WoW so the new code is loaded.
- The framework now rejects adopting its own live settings view/handle as raw
  SavedVariables, preventing the resulting recursive C stack overflow.
- Recovery from a poisoned framework profile store keeps accepting settings
  writes instead of only serving fallback defaults.
- Added SQP-defaults regression checks for old alias recovery, false/zero
  preservation, and serializable settings after recovery. The current SQP
  runtime already keeps the settings view local; no UI redesign is included.

Retail Interface remains `120105`, verified against installed build
`12.1.5.70391`. Existing Forever Interface `16001` is preserved; live Forever
testing is not claimed. Wago metadata/connection is unchanged.

## Before stable promotion

In Retail, verify `/sqp help`, `/sqp status`, `/sqp test`, quest nameplate
add/remove updates, options changes, profile switching and `/reload` persistence.
No SavedVariables deletion is required. This beta has automated Lua 5.1
evidence, not a claim of live client validation.
